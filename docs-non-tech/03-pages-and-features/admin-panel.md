# Admin Panel

**URL**: `/admin/dashboard`

## Purpose
For site administrators to manage the platform.

## Key Sections
- **Approvals**: A queue of properties and projects waiting for review.
- **Properties/Projects**: Searchable list of ALL listings on the site.
- **Users**: List of all registered users. Admins can ban users or change roles.
- **Blog**: Editor for creating and publishing news articles.
- **Settings**: Configuration for drop-down menus (Property Types, Amenities).
