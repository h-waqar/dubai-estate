# Pricing Page

**URL**: `/pricing`

## Purpose
Allows users to choose a subscription plan to start listing properties.

## Features
- **Plan Cards**: Displays available plans (e.g., Free, Silver, Gold).
- **Details**: Shows price, number of listings allowed, and duration.
- **Subscribe Button**: Initiates the payment process.

## Behavior
- If logged out: Clicking "Subscribe" redirects to Login.
- If logged in: Clicking "Subscribe" opens the PayPal payment window.
