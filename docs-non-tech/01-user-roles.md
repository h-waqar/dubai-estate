# User Roles

Different users have different permissions on the site.

## 1. Visitor (Guest)
- **Can**:
  - Browse and search all properties and projects.
  - Read blog posts.
  - Use the "Contact Us" form.
  - Register for a new account.
- **Cannot**:
  - List properties.
  - View contact details of some agents (depending on settings).

## 2. User (Registered)
- **Can**:
  - All Visitor features.
  - Access the "Account Dashboard".
  - Subscribe to a pricing plan.
  - Submit properties for listing (requires a subscription).
  - Manage their own profile.
- **Cannot**:
  - Approve their own properties (must be approved by Admin).

## 3. Admin
- **Can**:
  - Access the "Admin Dashboard".
  - Approve or Reject property listings submitted by users.
  - Manage blog posts (create, edit, delete).
  - View all user accounts and subscriptions.
  - Manage website settings (Categories, Features, etc.).

## 4. Super Admin
- **Can**:
  - Everything an Admin can do.
  - Manage other Admins (promote/demote).
