# What is Dubai Estate?

**Dubai Estate** is a website for buying, selling, and renting properties in Dubai. It connects real estate agents and developers with potential buyers and renters.

## Key Features

- **For Buyers/Renters**:
  - Search for homes (Villas, Apartments, etc.).
  - View off-plan projects (properties currently being built).
  - Read blog articles about the market.
  - Contact agents directly.

- **For Agents/Sellers**:
  - List properties for sale or rent.
  - Manage inquiries (leads).
  - Subscribe to listing plans (Silver, Gold, etc.).

- **For Administrators**:
  - Approve or decline new property listings.
  - Manage users and subscriptions.
  - Post blog content.
