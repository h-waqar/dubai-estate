# Posting Content (Property)

**Goal**: List a new apartment for sale.

1.  **Dashboard**: Go to `/account/properties`.
2.  **New**: Click "Add New Property".
3.  **Form**:
    - **Basic Info**: Enter Title, Price, Type (Apartment), Listing Type (Sale).
    - **Details**: Enter Bedrooms, Bathrooms, Area.
    - **Location**: Enter address and select on map.
    - **Media**: Upload photos.
4.  **Submit**: Click "Create Property".
5.  **Status**: The property appears in your list as "Pending Review".
6.  **Wait**: An Admin must approve it before it appears in search results.
