# How to Subscribe

**Goal**: Purchase a plan to list properties.

1.  **Navigate**: Go to the `/pricing` page.
2.  **Select**: Click the button on the desired plan.
3.  **Payment**: A PayPal popup appears. Log in to PayPal and approve the payment.
4.  **Confirmation**: The popup closes. The page updates to show "Active Subscription".
5.  **Result**: You can now post properties up to the limit of your plan.
