# How the Site Works

## The Listing Process
1.  **Sign Up**: An agent registers an account.
2.  **Subscribe**: The agent selects a plan (e.g., "Gold Plan") and pays via PayPal.
3.  **Create**: The agent fills out a form to list a new property (photos, price, location).
4.  **Review**: The property status is set to "Pending Review". It does NOT appear on the public site yet.
5.  **Approval**: An Admin checks the listing. If approved, it goes "Live" and is visible to everyone.

## The Buying/Renting Process
1.  **Search**: A buyer filters properties by location, price, and type.
2.  **View**: The buyer clicks a property to see photos and details.
3.  **Inquire**: The buyer fills out a "Contact Agent" form.
4.  **Connect**: The agent receives the inquiry and contacts the buyer.
