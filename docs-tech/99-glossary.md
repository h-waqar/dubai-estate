# Glossary (Tech)

- **RSC**: React Server Component. Components that run only on the server.
- **Server Action**: Asynchronous function executed on the server, callable from Client Components.
- **Prisma**: The ORM used for database interactions.
- **Zod**: Schema validation library.
- **Shadcn**: A collection of re-usable components built with Radix UI and Tailwind CSS.
- **Turnstile**: Cloudflare's CAPTCHA alternative.
- **DTO**: Data Transfer Object.
- **RBAC**: Role-Based Access Control.
